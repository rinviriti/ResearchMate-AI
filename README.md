# 📚 ResearchMate AI

### Multi-Agent Research Paper Assistant Powered by Gemini

ResearchMate AI is an AI-powered multi-agent system that helps researchers, students, and academics analyze scientific papers automatically.

Upload a research paper in PDF format and receive a structured research report generated by specialized AI agents for summarization, methodology analysis, evaluation, research mentoring, and safety review.

Built as a capstone project for the **Google × Kaggle AI Agents Intensive: Vibe Coding Course 2026**.

---

## ✨ Key Features

* 📄 Research paper PDF analysis
* 🤖 Multi-agent architecture
* 🔬 Methodology extraction
* 📊 Results and evaluation review
* 🎓 Research mentorship recommendations
* 🛡️ Safety and reliability assessment
* 📑 Downloadable final reports (Markdown & PDF)

## 🧠 Multi-Agent Architecture

```text
User
 │

 ├── 📄 Summary Agent
 ├── 🔬 Methodology Agent
 ├── 📊 Evaluation Agent
 ├── 🎓 Research Mentor Agent
 └── 🛡️ Safety Review Agent
 │
 ▼

```

---

## 🤖 Agent Overview

| Agent                    | Purpose                                                       |
| ------------------------ | ------------------------------------------------------------- |
| 📄 Summary Agent         | Generates concise research summaries                          |
| 🔬 Methodology Agent     | Extracts methods, datasets, and workflows                     |
| 📊 Evaluation Agent      | Reviews results, metrics, and limitations                     |
| 🎓 Research Mentor Agent | Suggests future work and research ideas                       |
| 🛡️ Safety Review Agent  | Identifies risks, unsupported claims, and missing disclaimers |

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/rinviriti/ResearchMate-AI.git
cd ResearchMate-AI
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure API Key

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

### Run Application

```bash
streamlit run app.py
```
